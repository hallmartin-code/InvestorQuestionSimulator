# Web fonts

Self-hosted so the Content-Security-Policy can stay `font-src 'self'` and visitors' browsers never contact a
third-party font CDN. Latin subsets, variable weight, WOFF2. All three families are licensed under the
SIL Open Font License 1.1 (https://openfontlicense.org).
